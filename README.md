## Descrizione del Progetto
Progettazione di un'applicazione locale per dispositivi mobili per fornire a tutte le tipologie di pescatori dilettanti uno strumento per salvare informazioni e dati sui personali luoghi di pesca.

## Provare l'app (Android)

Non serve installare Flutter: ogni versione pubblicata ha il file di installazione nella pagina **Releases** del repository.

1. Dal telefono Android apri la pagina *Releases* e scarica il file `.apk` dell'ultima versione (es. `diario-pesca-v0.1.1.apk`).
2. Apri il file scaricato. La prima volta Android chiede di consentire l'installazione da quella app (Chrome, File…): attiva *Consenti da questa fonte* e torna indietro.
3. Tocca *Installa*. Play Protect può avvisare che l'app non viene dal Play Store: scegli *Installa comunque*.

Per aggiornare l'app si installa allo stesso modo l'APK della versione nuova: i dati restano. Prima di aggiornare conviene comunque fare un backup dall'app (*Pescate → ⋮ → Backup e ripristino*).
